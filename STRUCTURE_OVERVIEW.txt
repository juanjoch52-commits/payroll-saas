🚀 GET STARTED IN 3 STEPS
═══════════════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES
   $ npm install

2. CONFIGURE ENVIRONMENT
   $ cp .env.example .env.local
   # Add your Supabase credentials

3. START DEVELOPMENT SERVER
   $ npm run dev
   # Visit http://localhost:3000
