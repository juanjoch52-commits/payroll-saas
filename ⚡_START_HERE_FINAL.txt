🚀 3 PASOS PARA LANZAR (10 minutos):

  PASO 1️⃣  - Subir a GitHub (2 minutos)
  ─────────────────────────
  En Terminal, ejecuta:
  
    cd ~/Desktop/payroll-saas  # (o donde tengas la carpeta)
    bash PUSH_TO_GITHUB.sh
  
  ✅ Eso es todo para GitHub

  PASO 2️⃣  - Configurar Vercel (5 minutos)
  ─────────────────────────
  1. Ve a: https://vercel.com/dashboard
  2. Haz clic: "Add New" → "Project"
  3. Selecciona: "payroll-saas"
  4. Vercel auto-detecta Next.js
  5. Configura variables de entorno (ver abajo)
  6. Haz clic: "Deploy"

  PASO 3️⃣  - Espera (3-5 minutos)
  ─────────────────────────
  Vercel compila y despliega automáticamente
  Tu app estará en: https://payroll-saas.vercel.app 🎉

════════════════════════════════════════════════════════════════════════════

🔑 VARIABLES DE ENTORNO PARA VERCEL:

Necesitarás estas 6 variables de tu Supabase:

  NEXT_PUBLIC_SUPABASE_URL = https://project-epd7f.supabase.co
  
  NEXT_PUBLIC_SUPABASE_ANON_KEY = [de Supabase → Settings → API → anon key]
  
  SUPABASE_SERVICE_ROLE_KEY = [de Supabase → Settings → API → service key]
  
  DATABASE_URL = [de Supabase → Settings → Database → Connection Pooling]
  
  NEXT_PUBLIC_APP_URL = https://payroll-saas.vercel.app
  
  NEXT_PUBLIC_DEFAULT_LOCALE = en
