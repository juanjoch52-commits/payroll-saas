📖 INSTRUCCIONES RÁPIDAS (5 PASOS)

1️⃣  OBTÉN TUS CREDENCIALES DE SUPABASE
   ├─ Ve a: https://supabase.com
   ├─ Crea un proyecto nuevo
   ├─ Copia 3 keys (Settings → API)
   └─ Ver: SETUP_SUPABASE.md para detalles

2️⃣  CONFIGURA TUS CREDENCIALES
   ├─ $ cp .env.example .env.local
   ├─ Abre .env.local en VS Code
   ├─ Pega tus 3 credenciales
   └─ Guarda el archivo

3️⃣  INSTALA DEPENDENCIAS
   ├─ $ npm install
   ├─ Espera 2-3 minutos
   └─ No cierres la terminal

4️⃣  APLICA MIGRACIONES (OPCIONAL)
   ├─ $ npm run db:push
   ├─ Crea las tablas en base de datos
   └─ Espera a que termine

5️⃣  LANZA EL SERVIDOR
   ├─ $ npm run dev
   ├─ Espera: "Ready in X.XXs"
   ├─ Abre: http://localhost:3000
   └─ ¡Listo! 🎉

4. Pega en .env.local

Si tienes dudas, lee: SETUP_SUPABASE.md

🚨 PROBLEMAS COMUNES

"npm command not found"
└─ Instala Node.js desde https://nodejs.org

"NEXT_PUBLIC_SUPABASE_URL is not set"
└─ .env.local no tiene las credenciales
└─ Verifica: cat .env.local

"Cannot connect to Supabase"
└─ Verifica que la URL es correcta (incluye https://)
└─ Regenera las keys en Supabase si es necesario

"Port 3000 already in use"
└─ Otra app usa puerto 3000
└─ Intenta: PORT=3001 npm run dev
